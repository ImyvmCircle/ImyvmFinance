# 开发规则索引

## 读取顺序

1. `AGENTS.md`
2. 本文件
3. 与任务相关的专项 instruction
4. 产出或改写正式文字时读取 `agents/WRITING_STYLE.md`

- `minecraft-i18n.instructions.md`：玩家可见文本、语言文件和 MessageFormat。

- `imyvm-mechanism-tech-principles.instructions.md`：IMYVM 机制资源交易与结算技术原则。
- `commands-suggestions.instructions.md`：命令注册、参数和建议项。
- `documentation-validation.instructions.md`：README、changelog 和验证命令。

- `player-documentation-perspective.instructions.md`：README 的用户侧文档视角。
